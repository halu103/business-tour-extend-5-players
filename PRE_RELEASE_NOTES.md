# Previous prerelease packages

The current package is **0.2.2 English installer release**. Its changes, verification limits
and safe installation instructions are in [RELEASE_NOTES.md](RELEASE_NOTES.md)
and [README.md](README.md).

The published preview.1 and preview.2 archives remain frozen and separate.
Their historical notes stay inside those archives. Preview.2 uses an earlier
32-cell implementation; it must not be mixed with this native 40-cell V3
release. The later preview.3/V2 development DLL was tested locally, not
published as an interchangeable release package.

A release filename does not establish five-human-client online stability.
The final changes were packaged without reopening the game, at the user's
request. Start with a private, no-bet bot room and observe the known limits.
